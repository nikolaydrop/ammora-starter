# ammora-starter

Безопасный стартовый проект для знакомства с Ammora SDK на **тестовой сети GIWA Sepolia**.

- Только **чтение** данных из сети: никаких приватных ключей, кошельков и транзакций.
- Версии пакетов зафиксированы (`@ammora-protocol/sdk@0.2.13`, `viem@2.58.4`).
- `.npmrc` с `ignore-scripts=true` блокирует запуск скриптов установки у любых зависимостей.

## Запуск в GitHub Codespaces (не на вашем Mac)

1. Создайте на github.com **новый приватный репозиторий** и загрузите в него содержимое этой папки
   (кнопка *Add file -> Upload files*; не забудьте скрытые папку `.devcontainer` и файл `.npmrc`).
2. В репозитории нажмите зелёную кнопку **Code -> Codespaces -> Create codespace on main**.
3. Подождите, пока среда соберётся: зависимости поставятся сами (`postCreateCommand`).
4. В терминале Codespaces выполните:

```bash
npm run check
```

Ожидаемый результат: `OK: connected and deployment verified` и номер блока.

5. Котировка обмена (тоже только чтение, транзакций нет):

```bash
npm run quote -- <tokenIn> <tokenOut> <amountInRaw> 100
```

Адреса токенов берите из документации Ammora. `amountInRaw` - в минимальных единицах
(для токена с 18 знаками 1 токен = `1000000000000000000`). Последнее число - допустимое
проскальзывание в базисных пунктах (100 = 1%).

## Правила безопасности

- Не кладите в проект и не вставляйте в терминал приватные ключи и seed-фразы.
- Если дойдёте до отправки транзакций, используйте **отдельный пустой кошелёк** и только тестовую сеть.
- Не обновляйте версии пакетов вслепую: после обновления проверяйте пакет заново.
- Когда закончите, удалите Codespace (github.com/codespaces), чтобы не тратить лимиты.

## Что дальше

В SDK есть билдеры для запуска токенов (`buildCreateALCSegmentedV3Launch...`), ALMM-пулов и других
функций. Для заявки на конкурс нужен сайт на базе SDK: его можно собрать поверх этих же клиентов.
Условия конкурса читайте на официальном сайте Ammora.
